Example A — Page 7 (Packet Discarded) / مثال أ — صفحة 7 (رفض الحزمة)
An IPv4 packet has arrived with the first 8 bits as: 0100 0010. The receiver discards the packet. Why?
Solution:
Split the 8 bits into two 4-bit halves:
• VER = 0100 = 4 → IPv4 protocol is correct. ✅
• HLEN = 0010 = 2 → Header size = 2 × 4 = 8 bytes ✗
• The minimum number of bytes in the header must be 20 bytes. Since 8 < 20, the packet is corrupted in transmission and is discarded.
وصلت حزمة IPv4 حيث كانت أول 8 بتات هي: 0100 0010. يقوم المستقبل بالتخلص من الحزمة وتجاهلها. لماذا؟
الحل:
نقسم الـ 8 بتات إلى نصفين (كل نصف 4 بت):
• VER = 0100 = 4 ← بروتوكول IPv4 صحيح. ✅
• HLEN = 0010 = 2 ← حجم الهيدر = 2 × 4 = 8 بايت ✗
• يجب أن يكون الحد الأدنى لعدد البايتات في الهيدر هو 20 بايت. بما أن 8 < 20، فإن الحزمة تالفة وتتعرض للتلف أثناء الإرسال ويتم تجاهلها.
Example B — Page 7 (Options Bytes) / مثال ب — صفحة 7 (خيارات الهيدر)
In an IPv4 packet, the value of HLEN in binary is: 1000. How many bytes of options are being carried by this packet?
Solution:
• HLEN value is 1000 in binary, which is 8 in decimal.
• Total header size = 8 × 4 = 32 bytes.
• Base header size = 20 bytes.
• Options = Total Header − Base Header = 32 − 20 = 12 bytes of options ✓
في حزمة IPv4، قيمة HLEN بالثنائي هي: 1000. كم عدد بايتات الخيارات (options) التي تحملها الحزمة؟
الحل:
• قيمة HLEN هي 1000 بالثنائي، وهي تعادل 8 بالعشري.
• الحجم الكلي للهيدر = 8 × 4 = 32 بايت.
• حجم الهيدر الأساسي (بدون خيارات) = 20 بايت.
• حجم الخيارات = حجم الهيدر الكلي − الهيدر الأساسي = 32 − 20 = 12 بايت من الخيارات ✓
Example C — Page 11 (Data Size) ← Exam Question / مثال ج — صفحة 11 (حجم البيانات) ← سؤال امتحان
In an IPv4 packet, the value of HLEN is 5, and the value of the total length field is 40. How many bytes of data are being carried by this packet?
Solution:
• HLEN = 5 → Header size = 5 × 4 = 20 bytes (base header, no options).
• Total Length = 40 bytes.
• Data payload = Total Length − Header size = 40 − 20 = 20 bytes of data ✓
في حزمة IPv4، قيمة HLEN هي 5، وقيمة حقل الطول الكلي هي 40. كم عدد بايتات البيانات التي تحملها هذه الحزمة؟
الحل:
• HLEN = 5 ← حجم الهيدر = 5 × 4 = 20 بايت (الهيدر الأساسي، بدون خيارات).
• الطول الكلي = 40 بايت.
• حمولة البيانات = الطول الكلي − حجم الهيدر = 40 − 20 = 20 بايت من البيانات ✓

What is IPv6 & Its Rules?

• 128-bit address length = 32 hexadecimal values.
• Written as 8 groups of 4 hexadecimal digits (hextets) separated by colons.
• Does not use dotted-decimal subnet masks; uses prefix lengths (e.g. /64).

Rule 1: Omit Leading Zeros

Any leading zeros in any hextet can be omitted. e.g., 01AB → 1AB, 0000 → 0.

Rule 2: Double Colon (::)

A double colon (::) can replace any contiguous string of all-zero hextets. Can only be used ONCE.

ما هو IPv6 وقواعده؟

• طول العنوان 128 بت = 32 رقماً ست عشرياً.
• يُكتب على هيئة 8 مجموعات من 4 أرقام ست عشرية (hextets) مفصولة بنقطتين.
• لا يستخدم قناع شبكة عشري منقط؛ يستخدم طول البادئة (مثل /64).

القاعدة 1: حذف الأصفار القيادية

يمكن حذف أي أصفار قيادية في أي مجموعة. مثل: 01AB ← 1AB، 0000 ← 0.

القاعدة 2: النقطتان المزدوجتان (::)

تستبدل النقطتان المزدوجتان أي سلسلة متتالية من مجموعات الأصفار الكاملة. وتستخدم مرة واحدة فقط.

Rule 1 Examples / أمثلة القاعدة 1

01AB → 1AB
09F0 → 9F0
00AB → AB
0000 → 0

Rule 2 Example / أمثلة القاعدة 2

2001:0DB8:0000:0000:0000:0000:0000:0200
→ 2001:DB8::200

What is a Wildcard Mask?

• A Wildcard Mask is the exact inverse (opposite) of a Subnet Mask.
• It is widely used in Cisco IOS Access Control Lists (ACLs) and routing protocols like OSPF to match traffic.
• Rule of matching: A 0 bit means "must match the address bit exactly", while a 1 bit means "ignore this address bit" (wildcard).

The Math: Subtraction Formula

To calculate a wildcard mask, simply subtract the subnet mask from the Full Mask (where all binary bits are 1, which equals 255.255.255.255):

Wildcard Mask = 255.255.255.255 − Subnet Mask

ما هو قناع الـ Wildcard؟

• قناع الـ Wildcard هو العكس (المعكوس) لقناع الشبكة (Subnet Mask) تماماً.
• يُستخدم على نطاق واسع في قوائم التحكم بالوصول (ACLs) لأجهزة سيسكو وبروتوكولات التوجيه مثل OSPF لتحديد مطابقة البيانات.
• قاعدة المطابقة: بت الـ 0 يعني "يجب مطابقة بت العنوان تماماً"، بينما بت الـ 1 يعني "تجاهل هذا البت ولا يهم قيمته".

المعادلة الرياضية للحساب

لحساب قناع الـ Wildcard، نقوم ببساطة بطرح قناع الشبكة المعطى من **القناع الكامل** (الذي تكون جميع بتاته الثنائية تساوي 1، وهو ما يعادل 255.255.255.255):

Wildcard Mask = 255.255.255.255 − Subnet Mask

Quick Concept Guide for Beginners / الدليل السريع للمبتدئين

1. Subnet Mask to CIDR / تحويل القناع لعدد البتات:

Each 255 in the mask equals 8 bits. For example, 255.255.0.0 has two 255s, so it is a /16 mask. 255.255.255.0 has three 255s, so it is a /24 mask.

كل خانة تحتوي على الرقم 255 تساوي 8 بتات. مثلاً: القناع 255.255.0.0 يحتوي على خانتين 255، إذن قيمته /16 بت.

2. Borrowed Bits (n) / البتات المستعارة:

Look at the octet that changed. Convert that number to binary. The number of leading 1s is the number of borrowed bits (n). For example, 224 in binary is 11100000 which contains 3 ones, so we borrowed 3 bits.

ننظر للخانة التي تغيرت في القناع الجديد ونحول قيمتها للثنائي. عدد الواحدات هو عدد البتات المستعارة (n). مثلاً: الرقم 224 بالثنائي هو 11100000 (يحتوي على 3 واحدات)، إذن استعرنا 3 بتات.

3. Block Size (Jump Size) / حجم القفزة للشبكات:

Subtract the changed mask octet value from 256. If the new mask is 255.255.224.0, the changed octet is 224, so the Block Size is 256 - 224 = 32. This means network addresses increment by 32 in that octet.

نطرح قيمة الخانة المتغيرة في القناع من 256. مثلاً: إذا كانت الخانة 224، فالقفزة = 256 - 224 = 32. وهذا يعني أن عناوين الشبكات تزداد بمقدار 32.
